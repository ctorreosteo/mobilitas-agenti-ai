# Registro delle deviazioni dal metodo

Dove le regole interne di questo agente si sono rivelate sbagliate, incomplete o
controproducenti sul caso concreto.

## Come funziona

Il diritto di famiglia si muove, e le prassi dei singoli tribunali si muovono ancora di più. Una
regola scritta in un file di riferimento può essere superata da una norma nuova, da un
orientamento consolidato in senso contrario, o dalla prassi dell'ufficio davanti al quale stiamo
effettivamente discutendo.

**Quando il diritto verificato e il metodo interno non coincidono, vince il diritto verificato.**
Si scrive la versione corretta nell'atto, e si apre una voce qui.

- Chi trova una deviazione **nuova** apre una voce con stato `PROPOSTA` e la fonte verificata.
- **Non si modificano i file di riferimento**: la ratifica è umana.
- Chi scrive un atto legge questo file **prima**: evita di reintrodurre un errore già corretto
  altrove.
